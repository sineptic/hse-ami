# Инструкции для ИИ

## Проект

- Архив письменных ДЗ для ПМИ, 1 курс, М++, 2026/27. В `README.md` отдельные разделы по матанализу, алгебре, комбинаторике и топологии. Упорядочивай ДЗ по номеру и сохраняй прошедшие.
- Ссылки из README ведут прямо на PDF в `assignments/`. В README достаточно номера, короткой темы или дедлайна и ссылок на сдачу и результаты. Добавляй только письменные ДЗ и связанные с ними сведения, без решений.

## Источники и сроки

- Перед обновлением прочитай README и проверь `git status`. Сохрани чужие изменения.
- Используй четыре страницы Wiki из README для нужного года и потока. По топологии бери задания группы П+. Проверяй объявления, дедлайны и семинарские листки, в которых тоже может быть ДЗ. Читай новые и изменённые PDF целиком. Сравнивай содержимое файлов по прежним ссылкам с опубликованными заданиями.
- Сверяй сроки с Wiki и актуальными уточнениями владельца. При расхождении укажи его явно. В README указывай только даты дедлайнов. Если есть строгий и рекомендуемый сроки, ставь рекомендуемую дату в скобках после строгой и поясняй это под таблицей. При отсутствии подтверждённой даты пиши «Дата не указана». Наличие задач в PDF само по себе не подтверждает срок.
- Если Wiki недоступна, повтори запрос, попробуй Helium или Jina Reader для публичных страниц. По возможности сверяй кеш Jina с Wiki напрямую. Если источник проверить не удалось, сохрани прежние данные и сообщи об этом.

## PDF

- Скачивай оригиналы во временную папку вне репозитория. Сохраняй только раздел ДЗ целиком, включая подпункты, рисунки, звёздочки и продолжения на следующих страницах. При обрезке удаляй постороннее содержимое из PDF, включая извлекаемый текст. Сохраняй исходные формулы и векторный текст.
- Листки `topology-01.pdf`, `topology-02.pdf` и `topology-03.pdf` храни целиком. Номера заданных задач указывай в README.
- Имена файлов следуют шаблону `analysis-01.pdf`, `algebra-01.pdf`, `combinatorics-01.pdf`, `topology-01.pdf`. Для отдельных БДЗ и звёздочек используй существующие шаблоны имён. Отрендери и осмотри каждую страницу итогового PDF, сравни с оригиналом. В `assignments/` клади только готовые PDF.

## Приватность

- Сохраняй разрешённые ссылки на сдачу и результаты, включая нужные вкладки. Ссылку на таблицу самооценки недельных ДЗ по матанализу не добавляй и не восстанавливай. В README можно оставить напоминание об отметках. Ссылка на итоговые результаты по матанализу разрешена.
- Сохраняй приватность репозитория и настройки доступа. Перед возможным открытием репозитория предупреди владельца, что запрещённая ссылка есть в ранних коммитах. Историю не переписывай. Не публикуй данные из ведомостей и не отправляй приватные ссылки в Jina.
- Обновление хаба не включает сдачу работ, правку таблиц, вступление в классы и переписку с преподавателями.

## Публикация

- Меняй общую дату «обновлено» после проверки всех доступных источников по четырём предметам. При частичной проверке сохраняй общую дату.
- Проверь ссылки и порядок номеров, сверь заголовки PDF, просмотри diff и выполни `git diff --check`. Добавляй в коммит только изменения по задаче. Избегай пустых коммитов и пересохранения одинаковых PDF.
- По запросу на обновление коммить и отправляй проверенные изменения в `origin/main` обычным push. Для черновика или локальной правки оставляй изменения локально. Проверь результат push, коротко перечисли изменения и дай ссылку на репозиторий.
